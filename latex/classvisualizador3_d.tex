\doxysubsection{Detailed Description}
Interactive application for the visualization of Mohr\textquotesingle{}s Circle and the 3D stress state. 

Extends {\ttfamily \doxylink{classolc_1_1_pixel_game_engine}{olc::\+\+Pixel\+Game\+Engine}} to render a graphical interface that includes:
\begin{DoxyItemize}
\item A matrix editor for the Cauchy Stress Tensor.
\item A 3D representation of the differential element subjected to stresses.
\item A 2D diagram of Mohr\textquotesingle{}s Circle.
\item A retro CRT post-\/processing effect (barrel distortion). 
\end{DoxyItemize}
