Detailed Description

Layout and positioning constants for rendering the matrix on screen.

Defines the dimensions, font scaling, and origin coordinates used by the graphics engine to draw the visual representation of the Cauchy Stress Tensor (3x3 matrix) and its brackets in the user interface.
