◆ Format2Dec()

std::string Format2Dec ( float val)
inline

Converts a floating-point number to a formatted string with exactly two decimal places.

Uses a string stream (ostringstream) alongside format manipulators (std::fixed and std::setprecision) to ensure uniform representation. This is essential for rendering clean numerical data in the interface (such as principal stresses, tensor components, and Mohr's Circle data).

Parameters
[in]valNumeric float value to format.
Returns
Text string (std::string) with the value represented to two decimal places (e.g., 15.00).

◆ tryStof()

float tryStof ( const std::string & str)
inline

Safely converts a text string to a floating-point number (float).

Designed to process user inputs intended for the Cauchy Stress Tensor matrix. Automatically handles edge cases and standard C++ exceptions (empty strings, incomplete signs, or out-of-range values) to prevent the application from crashing. Additionally, normalizes the value '-0.0f' to '0.0f' to avoid display issues.

Parameters
[in]strText string (std::string) entered by the user in the interface.
Returns
The numeric value converted to float if the format is valid.
0.0f if an invalid input is detected, is empty, or throws an exception.
