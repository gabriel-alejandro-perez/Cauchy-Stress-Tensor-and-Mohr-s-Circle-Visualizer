Detailed Description

Precalculated mapping structure for the CRT monitor visual filter.

Stores screen coordinates transformed by barrel distortion (Brown-Conrady) along with their corresponding vignette attenuation factor. Allows applying the CRT effect via a Lookup Table (LUT), avoiding expensive geometric function calculations per pixel on every frame.
